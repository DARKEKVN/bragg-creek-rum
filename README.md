# Bragg Creek Rum

Five-page static Vite website for a fictional private dark rum brand.

## Pages

- `index.html` - Home
- `about.html` - About Snake
- `rum.html` - The Rum
- `barrel-room.html` - Barrel Room
- `booking.html` - Booking form

## Commands

```sh
npm run dev
npm run build
npm run preview
```

The booking form is frontend-only for now and does not expose a public phone number or email address.
